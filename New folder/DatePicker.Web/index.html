Modern DatePicker & DateTimePicker

Self-contained component replacing NuGet package Bootstrap.v3.Datetimepicker.CSS. Fully compatible with Bootstrap 5, jQuery, and Vanilla JS. Try any option combination in the playground.

No NuGet Required
1. Standard Date Picker

Standard date picker with format YYYY-MM-DD and calendar icon.

2. Date & Time Picker

Combined Date and Time picker with toolbar buttons (Today, Clear, Close) and YYYY-MM-DD HH:mm format.

3. Time Only Picker

12-hour clock with AM/PM toggle using format hh:mm A.

4. Constraints: Min/Max & Disabled Weekends

Only weekdays selectable, bounded between 10 days ago and 30 days from now.

5. Vanilla JavaScript (No jQuery Required)

Instantiated via new DateTimePicker(el, options).

6. Inline Calendar

Always-visible calendar widget (inline: true).

Selected Date: Today
